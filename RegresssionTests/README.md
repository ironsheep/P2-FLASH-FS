# RegresssionTests

The regression test programs for the Flash FS driver, and the log of each program's last run. [Running the regression tests](../CONTRIBUTING.md#running-the-regression-tests) says how to build and run them.

Each program prints a `RESULT:` line with its pass and fail counts when it ends, and the runner reads that line. The counts were measured on v2.1.0 on a P2 Edge at a 320 MHz system clock, built with pnut-ts v1.55.12. Every program passed: 2,126 tests in 21 programs, plus the 19 checks of the timing program. The log beside each program is the log of that run.
